# משקם הבית

אתר של משקם הבית: שיקום וחיזוק מבנים והסרת צו מבנה מסוכן באזור המרכז.

## מה יש כאן
- `index.html` – דף הבית (עמוד אחד, בלי תלות בכלים חיצוניים).
- `img/` – תמונות האתר.
- `privacy.html` – מדיניות פרטיות.
- `accessibility.html` – הצהרת נגישות.
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` – הסמל של האתר.

- להחליף את מספר הטלפון לדוגמה `050-555-0182` במספר האמיתי (כולל בקישורי הוואטסאפ `wa.me/972505550182`).
- להשלים בהצהרת הנגישות ובמדיניות הפרטיות את שם רכז הנגישות וכתובת הדואר האלקטרוני (מסומנים ברקע כתום).
- להוסיף מספר קבלן רשום (מופיע כ"יתווסף").

- להחליף בהמשך את התמונות שנוצרו במחשב בצילומים אמיתיים מהעבודות.

## העלאה לאוויר בחינם
אפשר להפעיל את האתר דרך GitHub Pages: בהגדרות המאגר, בפרק Pages, לבחור את הענף `main` ואת התיקייה הראשית.

## עמודי נחיתה לקמפיין בגוגל
הכותרת בראש הדף משתנה לפי הכתובת שהמודעה שולחת אליה:
- `?s=` סוג השירות: `tzav` (הסרת צו), `amudim` (עמודים), `mirpasot` (מרפסות), `hizuk` (חיזוק מבנים), `hipui` (חיפוי ואריחים), `betonim` (שיקום בטון).
- `?c=` העיר: `tel-aviv`, `ramat-gan`, `givatayim`, `petah-tikva`, `bnei-brak`, `holon`, `bat-yam`, `rishon`, `herzliya`, `ramat-hasharon`, `kiryat-ono`, `rosh-haayin`.

לדוגמה: `/?s=amudim&c=petah-tikva` מציג "שיקום ועיבוי עמודים בפתח תקווה".
גולש שמגיע ממודעה (או עם `?s=`) רואה ראש דף בלי תפריט, עם כפתור חיוג וכפתור הערכה בחינם.

## עמודי ערים
לכל עיר יש עמוד משלו בכתובת `/shikum-mivnim/<עיר>/`, עם תוכן ייחודי: מה מאפיין את הבניינים בעיר, הליקויים הנפוצים, שכונות ושאלות נפוצות.
התוכן של כל העמודים נמצא בקובץ אחד בצד הבנייה, והעיצוב משותף בקובץ `assets/site.css`.
הקבצים `sitemap.xml` ו־`robots.txt` עוזרים לגוגל למצוא את כל העמודים. אחרי העלייה לאוויר כדאי להגיש את מפת האתר בכלי של גוגל לבעלי אתרים (Search Console).
